## Watermark Under Article 50

An adversarial evaluation harness for text provenance systems. It compares a from-scratch green-list watermark with the open-source SynthID-Text implementation under paraphrasing, translation, token edits, truncation, and cross-model laundering, measuring detection at fixed false-positive operating points. The project combines reproducible ML engineering, statistical calibration, adversarial testing, data provenance, and policy-facing communication in an interactive explanation of when watermark evidence survives—and when it does not.

**Publication hold:** This language describes the planned artifact. Do not add it to a public portfolio until SynthID results, the report, the interactive, and deployment have passed their acceptance checks.
